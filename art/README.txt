EXTERNAL SPRITE OVERRIDES

Put PNG files here to replace the built-in code-drawn sprites.
The file name must match the internal key exactly, lower case is not allowed.

UNITS   KNIGHT0.png KNIGHT1.png LANCER0.png LANCER1.png ARCHER0.png ARCHER1.png
        MAGE0.png MAGE1.png CLERIC0.png CLERIC1.png
        PALADIN0.png PALADIN1.png DRAGOON0.png DRAGOON1.png SNIPER0.png SNIPER1.png
        ARCHMAGE0.png ARCHMAGE1.png BISHOP0.png BISHOP1.png
        ORC0.png ORC1.png WOLF0.png WOLF1.png BOWMAN0.png BOWMAN1.png
        SHAMAN0.png SHAMAN1.png HEAVY0.png HEAVY1.png

TILES   GRASS.png PATH.png WATER.png ROCK.png TREE.png FLOWER.png
        POISON.png SPRING.png HILL.png RUBBLE.png

Suffix 0 is the idle frame, suffix 1 is the walk frame.
Any pixel size works. The image is drawn into the unit or tile box,
so square images are expected. Transparent background required.
If a file is absent the built-in code-drawn sprite is used instead.
