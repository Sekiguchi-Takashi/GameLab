# GameLab HANDOFF

Godotで作るシミュレーションRPG本体と、その開発規約を1つにまとめたリポジトリ。
**リポジトリはこれ1つ。** 増やさない。

## 使い方

新しいチャットの冒頭に、この `HANDOFF.md` と `docs/RULE_ART.md` と `docs/RULE_CODE.md` を貼る。

## 構成

```
GameLab/
  project.godot          ゲーム本体
  Main.tscn
  scripts/
    Main.gd              ゲームループ、入力、カメラ、UI描画
    Board.gd             マップデータと地形描画
    Fx.gd                フラッシュ・揺れ・ヒットストップ・ダメージ数字
    Units.gd    autoload ユニットのステータス定義
    Art.gd      autoload スプライトとタイルのドットデータ
    Gfx.gd      autoload ビットマップフォント、テクスチャ生成とキャッシュ
    Pal.gd      autoload 配色
  .github/workflows/build.yml
  export_presets.cfg
  debug.keystore
  deploy.sh
  docs/
    HANDOFF.md
    RULE_ART.md          画作りの規約（確定）
    RULE_CODE.md         GDScriptの規約（確定）
    LOG/001_fclab.md     検証記録
```

## ビルドと配布

```
bash ~/GameLab/deploy.sh "コメント"
```

push すると GitHub Actions が走り、Releases に `build-<番号>` として APK が出る。
**エラーの一次発見者はClaude。** ユーザーに渡るのはビルドが通ったAPKだけ。

## 現在のゲーム内容（v5.4）

タクティクスオウガ型SRPGの土台。

- 画面 640x360、タイル 32x32、ユニット 48x48（`RULE_ART.md` 準拠）
- マップ 24x18 タイル。ドラッグでスクロール
- 地形: 草原 / 道 / 水（進入不可）/ 岩（進入不可・防御+3）/ 森（移動コスト2・防御+2）/ 花
- ユニット6種: KNIGHT / LANCER / ARCHER / MAGE（味方）、ORC / WOLF（敵）
- 選択 → 移動範囲表示 → 移動 → 攻撃対象選択 → 攻撃
- 反撃あり（射程が届く場合）
- クリティカル（ダメージ1.5倍）
- ターン制、敵AIは最寄りの味方に接近して攻撃
- 勝敗判定、リスタート

### v2.1 で追加（手触り）

- **アニメーションキュー方式**に作り替え。行動を積んで順に再生する。再生中は入力を受け付けない
- 移動は経路を1マスずつ歩く。歩行2コマが動き、進行方向に向きが変わる。カメラが追従する
- 攻撃は対象へ踏み込んで戻る。命中の瞬間に演出が乗る。反撃も同じ流れ
- 被弾で白く光り、後ろへのけぞる。撃破はフェードアウト
- **2回タップで確定**。1回目で経路と情報を表示、2回目で実行。攻撃も同じ（ダメージ予測を表示）
- 経路を黄色い線で表示し、実際にその道を歩く
- 敵ターンは敵ごとにカメラが寄り、間を置いてから動く
- ターン開始時に画面中央にバナー
- 地形情報パネル（コスト・防御）、クリティカル表示

## 操作

- ユニットをタップ → 青い移動範囲が出る
- 範囲内のマスをタップ → 移動
- 赤く光る敵をタップ → 攻撃。`WAIT` で待機
- 画面をドラッグ → マップスクロール
- 右下 `END TURN` → 敵ターンへ

## v2.3 で追加（戦術）

- **クラススキル**（MP消費、残数制）
  - KNIGHT GUARD: 次の手番まで被ダメ半減
  - LANCER PIERCE: 対象とその後ろの敵を同時に攻撃
  - ARCHER SNIPE: 射程3、x1.3、反撃なし
  - MAGE BLAST: 十字5マス、x0.9、反撃なし
  - CLERIC HEAL: 隣接味方を回復（新クラス）
- **EXPとレベルアップ**。攻撃12、撃破+30。100でレベル+1（HP+4 ATK+1 DEF+1）
- **敵AIの改善**。到達可能な全マスと全標的の組み合わせを評価。撃破可能を最優先、地形防御を加点、射程持ちは距離を取る
- **CHECK画面**。上部バー右の `CHECK` から開く。確認項目をタップで OK / NG に切り替え、`COPY RESULT` でクリップボードへ

## 検証の受け渡し

確認項目はアプリ内の `CHECK` 画面にある。触って OK / NG を付け、`COPY RESULT` を押してチャットに貼れば、Claudeがそのまま受け取る。
項目は `scripts/Check.gd` の `ITEMS` にあり、バージョンごとにClaudeが書き換える。

## v3.0 で追加（ゲームとしての形）

**画面構成を分割した。** `App.gd` が画面遷移を管理する。

```
TITLE -> PREP -> TALK(intro) -> BATTLE -> TALK(outro) -> PREP(next) ... -> END
```

- `App.gd` 画面遷移
- `Title.gd` タイトル（NEW GAME / CONTINUE / CHECK LIST）
- `Prep.gd` 出撃準備（隊員のレベルとHPを一覧、DEPLOY で開始）
- `Talk.gd` 会話（1文字送り、タップでスキップ・送り）
- `Battle.gd` 戦闘（旧 Main.gd）
- `Maps.gd` autoload / 4マップの地形・敵配置・勝利条件・会話
- `Save.gd` autoload / `user://save.json` への保存と隊員の引き継ぎ

**4マップと勝利条件**

| # | 名前 | 条件 |
|---|---|---|
| 1 | PLAINS | 敵全滅 |
| 2 | RIVER | 敵将撃破（王冠マーク付き、強化個体） |
| 3 | FORT | 指定タイル到達（黄色く光る） |
| 4 | PASS | 6ラウンド生存 |

地形は `Maps.gd` に文字列で定義。`.`草原 `-`道 `~`水 `#`岩 `T`森 `f`花。

**引き継ぎとセーブ**

レベル・EXP・成長したステータスは次のマップへ持ち越す。HPとMPは戦闘前に全回復。
勝利のたびに `user://save.json` へ保存し、タイトルの CONTINUE で再開できる。

**CHECK画面**はタイトルから開く。項目は `scripts/Check.gd` の `ITEMS`。

## v3.2 で追加（日本語 + 音）

### 日本語表示

`Gfx.gd` が起動時にAndroidのシステムフォントを探して読み込む（`/system/fonts/NotoSansCJK-Regular.ttc` など8候補）。
見つかれば日本語、見つからなければ従来の英字ビットマップフォントにフォールバックする。**追加ファイルの同梱なし。**

- `Gfx.has_jp()` — 日本語フォントが使えるか
- `Gfx.L(ja, en)` — 使えれば日本語、なければ英語を返す
- `Gfx.jtext(ci, s, pos, col, size)` — 日本語描画。フォント無しなら英字ビットマップにフォールバック
- `Gfx.jwidth(s, size)` — 文字幅

日本語文字列は各所に `Gfx.L("攻撃", "ATTACK")` の形で埋め込む。マップ名・目的・会話は `Maps.JA`、
クラス名・技名は `Units.JA_NAME` / `Units.JA_SKILL` にまとめてある。

タイトル左下に読み込んだフォント名（または `NONE`）を表示している。

### 音

`Sound.gd` autoload。**素材ファイルなし、全て波形をコードで生成**する。

- `AudioStreamWAV` を実行時に組み立ててキャッシュ
- 効果音8種: select / confirm / cancel / slash / hit / heal / down / level
- BGM4曲: title / battle / win / lose。矩形波（主旋律）＋三角波（ベース）＋ノイズ（打楽器）の3声
- 曲データは `Sound.SONGS` に16分音符単位の配列で定義
- タイトルの `音 ON/OFF` で切替

### 地形4種を追加

| タイル | コスト | 防御 | 効果 |
|---|---|---|---|
| POISON 毒沼 | 2 | 0 | ラウンド開始時に-3 |
| SPRING 泉 | 1 | 0 | ラウンド開始時に+4 |

射程ボーナスは `eff_rng()` で計算し、攻撃・反撃・敵AIすべてに反映される。

### 道具

隊で共有する消耗品。個数は `Save.items` に持ち、マップ間で持ち越す。勝利で傷薬と投げ石が1つずつ補充される。

- 傷薬 POTION: 射程1の味方（自分含む）のHPを15回復
- 活力の実 NUT: 自分のMPを2回復。対象選択なし
- 投げ石 STONE: 射程3の敵に7ダメージ

行動ボタンは `攻撃 / 技 / 道具 / 待機` の4つになった。

### マップ検査の強化

マップの構文（行数・幅・文字種）、初期配置が通行可能か、味方から全敵と目標地点へ到達できるかを
ビルド前に機械的に検査する。v3.1の検査は正規表現が甘く一部しか見ていなかったので作り直した。

## v3.9 / v4.0 で追加

### 武器（v3.9）

5系統×3段階。職種ごとに装備できる系統が決まる（`Units.WTYPE`）。
上位品は射程+1のものがある。敵撃破で約34%ドロップし、勝利時に倉庫へ入る。
出撃準備で隊員の行をタップすると隊員詳細画面（`Detail.gd`）が開き、装備変更と昇格を行う。

### 演出（v4.0）

`Fx.gd` に武器系統別のエフェクトを実装。全てコード描画。

- slash 斬撃の弧 / thrust 突きの伸縮 / arrow 飛翔する矢 / magic 詠唱円と爆散 / holy 光柱 / heal 上昇粒子 / guard 展開する盾環
- クリティカルは大きく黄色で表示、回復は緑で `+N`
- HPバーは赤い残像が遅れて追従する
- 戦闘開始時にマップ全体をカメラでパンしてから開始
- 勝利は上下から帯が閉じて生存者が整列、敗北はゆっくり暗転
- 対象選択中はモードボタンが脈動する

### クラッシュ修正（v3.5〜v3.8）

原因は**BGMのループ終端をサンプル数そのものに設定していたこと**。1サンプル分だけ配列外を読み、
ループ地点で必ず落ちていた。ループ処理を使わず `finished` シグナルで再生し直す方式に変更。
あわせて、画面遷移のシグナルを `CONNECT_DEFERRED` にし、入力伝播中のツリー操作を排除した。
どちらも `RULE_CODE.md` に規約として記載済み。

`user://trace.txt` に画面遷移の記録を書き、次回起動時のタイトル画面に前回の最後の記録を表示する
仕組みを入れてある。クラッシュの位置特定にはこれが決定的だった。

### 4方向スプライト

`<KIND>_D0` 正面（下向き） / `_D1` 側面（右向き、左は反転） / `_D2` 背面（上向き）。
`b` を付けると歩行コマ。`Gfx.unit_key(kind, dir, frame)` が存在するものを順に探し、
無ければ方向0、それも無ければコード内ドット絵へ落ちる。

### 向き選択フェーズ

行動を終えたユニットは、手番を終える前に向きを選ぶ。`下 / 左 / 上 / 右` のボタン、
またはマップをタップして方向を指定する。側面から+20%、背面から+50%を受けるため、
どちらを向いて終えるかが駆け引きになる。敵は移動・攻撃した方向を自動で向く。

### 素材の保管

`artsrc/` に背景を抜いた原画（512x512）を全方向分保管。`.gdignore` によりGodotは読み込まない。
サイズや色数を変えたくなったらここから作り直す。**生成AIに描き直させる必要はない。**
